🔑 A chave do Claude Console

É a chave que paga as respostas do Buddy. Ela fica guardada no servidor e nunca volta para esta tela: depois de salva, só aparecem os quatro últimos caracteres.

  1. Abra console.anthropic.com e entre na conta da escola.
  2. Crie um workspace só para o Buddy (por exemplo "Buddy Fisk") e, nele, defina o limite de gasto mensal. É a trava que vale mesmo se algo aqui falhar.
  3. Nesse workspace, crie uma chave de API comum (não a de administração) e copie.
  4. Cole aqui embaixo e salve. A tela confere a chave com o Console antes de guardar.
